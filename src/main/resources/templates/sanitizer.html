QUESTIONS

Before you paste your code.

What kind of Java code can I review? +

Controllers, services, repositories, entities, API implementations and other meaningful backend code are good starting points.

Can I review Spring Boot code? +

Yes. The current review experience is focused particularly on Java and Spring Boot development.

Does the tool guarantee a security vulnerability? +

No. Findings are review suggestions based on the submitted implementation. Important findings should be validated against the complete application.

Can the resume statements invent achievements? +

They should not. The sanitizer is instructed to keep resume statements grounded in the technical evidence present in the submitted code.

Will other programming languages be supported? +

The current experience is Java and Spring Boot focused. The same architecture can later be extended with language-specific review rules for Python, JavaScript, TypeScript, C#, Go and others.
